# SpeedBar v2

版本 `2.0.0`，适用于 Windows 11 x64。下载 `SpeedBar.exe` 即可运行，无需安装 .NET；也提供 ZIP 和 `SHA256SUMS.txt`。

## 主要变化

- 参考 TrafficMonitor 的全屏避让、按需定位及任务栏恢复思路，独立重写 WPF 显示生命周期；参考位置见仓库 `docs/v2-design.md`。
- 全屏、锁屏或任务栏不可用时隐藏并取消置顶，暂停新的指标采样及 UIA 扫描；连续安全至少 800 ms 后才恢复。
- 移除 Explorer owner/parent 依赖和旧嵌入路径，任务栏重建时保留主窗口；位置不变不反复移动，不循环抢回置顶。
- 新增托盘“暂停显示（游戏模式）”，供窗口化游戏手动暂停；“重新贴靠任务栏”仍遵守全屏保护。
- 单个 UIA 后台线程、布局缓存和过期保护；按网卡计算差值，暂停恢复重建采样基线；配置校验及原子保存。
- 保留既有配置字段；改进字号适配、DPI 坐标和安全空位判断，增加无依赖回归测试及 Windows CI。

## 验证

Release 构建零警告、零错误；68 项回归测试及 29 项隔离桌面原生烟测通过。烟测覆盖真实 MainWindow、指标计时器、UIA、全屏隐藏/恢复、模拟任务栏销毁重建和资源释放。

隔离桌面使用预置的“已观察到全屏窗口”状态，未验证真实前台事件、真实 Explorer 重启、混合 DPI 或独占 D3D 游戏。游戏帧时间尚未实测，不承诺所有游戏卡顿已消除。Windows 会话级全屏信号也可能使副屏游戏触发主屏显示隐藏。

## 升级

退出旧版后替换 EXE，保留原有 `%LOCALAPPDATA%\SpeedBar\settings.json`。显示隐藏时可从托盘打开设置或退出。
